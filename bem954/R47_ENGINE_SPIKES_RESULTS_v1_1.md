# Что важно для H1.27

1. Валидатор движка не заменяет наш проверщик графа: K-R3-07/K-R5-11 обязаны идти нашим кодом до развёртывания; в инварианты 12.3 добавить «из узла 7 ровно один исходящий поток, прямо в узел 8».
2. «Старт только сообщением» — свойство шлюза, не движка. REST движка закрыть от всех, кроме Kernel.
3. Health движка требует авторизации (без неё 401): сторожу сигнала 1 нужен свой путь или учётка только на чтение.
4. Истёкшая аренда возвращается через цикл сброса (~60 с), а не в момент истечения: учесть в таймаутах сигнала 2.
5. H2 с отложенной записью теряет фиксации при жёстком убийстве: только PostgreSQL (схема bem_engine, §8.4). Проба на PostgreSQL не выполнена — нужен JDBC-драйвер.
6. Сверка сигнала 3 нашла и обратное: экземпляры без работы в Kernel.
