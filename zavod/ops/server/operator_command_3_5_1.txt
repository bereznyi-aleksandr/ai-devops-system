# НАЗНАЧЕНИЕ: шаблон ОДНОЙ команды оператора для шага 3.5.1 (последняя строка файла). Оператор вставляет её в окно
#   SSH root, вошедшее по ключу, и при кодах 3 (перезагрузка) и 4 (второй вход по ключу) повторяет ТУ ЖЕ команду.
#   Подстановки: @COMMIT12@ — первые 12 знаков коммита выпуска; @FILE@ — имя архива; @URL@ — адрес файла выпуска;
#   @SHA256@ — сумма архива из журнала CI этого коммита (строка ZAVOD_SERVER_PACKAGE=OK … sha256=…), а НЕ из выпуска;
#   @EXTRA@ — у оператора пусто, в CI — малые размеры разделов машины GitHub. Других отличий у команды CI нет.
# ЧТО ДЕЛАЕТ: всё в подоболочке ( … ) — сбой не закрывает окно SSH.
#   Первый раз (папки /root/zavod-pkg-<коммит> нет): если архива /root/<имя> нет — скачивает его в НОВУЮ закрытую
#   папку (mktemp -d /root/zavod-dl-XXXXXX, 0700; каждый запуск — своя папка, прежние недокачанные файлы не трогаются);
#   сбой скачивания — отказ, недокачанный файл остаётся в этой папке; затем переносит архив в /root/<имя> без замены
#   (mv -nT) и проверяет, что перенос состоялся; имя уже занято — отказ, ничего не заменено, архив остаётся в папке;
#   сверяет сумму (sha256sum -c) ДО распаковки — не совпала: архив откладывается в новую папку /root/zavod-bad-XXXXXX,
#   отказ, ничего не распаковано; распаковывает в НОВУЮ временную папку (mktemp), ставит ей root:root 0755 до tar (verify_tree.py
#   closed требует 0755), затем переименовывает её без замены (mv -nT) в /root/zavod-pkg-<коммит>.
#   Повтор (папка есть): ничего не скачивает и не распаковывает поверх; снова сверяет сумму архива и побайтно опись
#   MANIFEST.sha256 из архива с описью в папке — отличие: отказ; затем установщик сам сверяет пакет целиком (шаг 0).
# ОГРАНИЧЕНИЯ: ничего не удаляет и не перезаписывает; секретов не содержит и не читает.
(set -eu; cd /root; C=@COMMIT12@; F=@FILE@; P=/root/zavod-pkg-$C; S=@SHA256@; ok_sum() { echo "$S  $F" | sha256sum -c --strict - || { B=$(mktemp -d /root/zavod-bad-XXXXXX); mv -nT "$F" "$B/$F"; echo "REFUSED: $F sum differs from the pinned one, set aside as $B/$F, nothing unpacked" >&2; exit 1; }; }; if [ -e "$P" ] || [ -L "$P" ]; then ok_sum; tar -xOf "$F" MANIFEST.sha256 | cmp -s - "$P/MANIFEST.sha256" || { echo "REFUSED: $P differs from $F: nothing changed" >&2; exit 1; }; echo "PACKAGE_DIR_EXISTS=$P (not unpacked again)"; else if [ ! -e "$F" ]; then D=$(mktemp -d /root/zavod-dl-XXXXXX); curl -fsSL -o "$D/$F" '@URL@' || { echo "REFUSED: download failed, partial file left in $D, nothing else changed" >&2; exit 1; }; { mv -nT "$D/$F" "$F" && [ ! -e "$D/$F" ]; } || { echo "REFUSED: /root/$F already exists, downloaded file left as $D/$F, nothing replaced" >&2; exit 1; }; fi; ok_sum; T=$(mktemp -d "$P.new-XXXXXX"); chmod 0755 "$T"; tar -C "$T" --no-same-owner -xf "$F"; mv -nT "$T" "$P"; [ ! -e "$T" ]; echo "PACKAGE_UNPACKED=$P"; fi; bash "$P/zavod/ops/server/install_stage_3_5_1.sh" "$P"@EXTRA@)
