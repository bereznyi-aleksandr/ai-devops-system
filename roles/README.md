# Постоянные области кураторов

Здесь находятся пять постоянных областей Завода.
Одна папка соответствует одной роли куратора. Роль и папка постоянны, чаты роли сменяются по задачам (протокол v2.5 Л.12).

В каждой папке:

- `ROLE.md` — обязанности и границы куратора;
- `MEMORY.md` — принятые решения и постоянные знания;
- `HANDOFF.md` — состояние для следующего чата куратора; лежит только на компьютере, в git не входит.

C1, C2, аналитик, исполнитель и аудитор работают временно.
Их код хранится в ветках GitHub.
Их временные файлы лежат в `C:\AI\zavod-runtime\temp\<задача>`.

`ROLE.md` и `MEMORY.md` хранятся в GitHub (ветка main) и меняются только через запрос на слияние (PR).
