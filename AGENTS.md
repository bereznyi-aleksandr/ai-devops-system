# Области кураторов Завода

Каждый чат роли куратора работает только в своей папке из `roles`. Роль и папка постоянны; чаты роли сменяются по задачам (протокол v2.5 Л.12), номер чата — A00001…Z99999.

| Чат | Рабочая папка |
|---|---|
| Завод · Куратор ГД | `roles/01_Куратор_ГД` |
| Завод · Производство · куратор | `roles/02_Куратор_производства` |

| Завод · Куратор рабочих контуров | `roles/05_Куратор_рабочих_контуров` |

Перед работой чат читает в своей папке `ROLE.md`, `MEMORY.md` и `HANDOFF.md`.
Перед завершением задачи и перед передачей при лимите поставщика куратор обновляет `HANDOFF.md`.
Постоянные знания и решения куратор записывает в `MEMORY.md`.
Куратор не меняет папку другого куратора без прямого поручения.
C1, C2 и рабочие роли не получают постоянные папки или чаты.
Их временная работа идёт в отдельной ветке GitHub и в `C:\AI\zavod-runtime\temp\<задача>`.
Секреты в этих файлах хранить нельзя.

Где живут эти файлы. Один источник текста правил — GitHub. Ветка `main` хранит последнюю слитую версию; действующей для нового чата считается только версия `active_rules_commit`, которую включили после всех шагов пути урока (протокол v2.5 Л.8, П.3, Е.2). Папка `C:\AI\zavod` — рабочая копия, а не второй оригинал, и всегда стоит на `main`.
Файлы правил перечислены в реестре `zavod/rules/RULES_REGISTRY.txt` (Д.7). Их и сам реестр меняют только так: ветка → правка → запрос на слияние (PR) → машинные проверки → независимый аудит → слияние владельцем уровня → включение. До включения новая версия из `main` новому чату как действующая не выдаётся.
`MEMORY.md` хранится в GitHub и меняется через PR, но правилом не является (временная замена записи в базе до пакета Н.15). `HANDOFF.md` и `handoff_archive/` лежат только на компьютере (`.gitignore`).
Начало нового чата: проверка «рабочая копия чистая» → `git pull --ff-only` в `C:\AI\zavod` → снова проверка чистоты и сверка реестра и каждого файла из него с `active_rules_commit` байт в байт. Только после совпадения чат читает свои файлы. Пока в ядре нет этой функции (пакет Z-RULES-01), проверку делает мод `zavod-handoff` (`rules_check`), а номер действующей версии лежит в `C:\AI\zavod-runtime\state\active_rules.json`.
`git pull --ff-only` не включает новую версию правил сам по себе. Любая проверка не прошла — чат ничего не меняет и сообщает Куратору ГД. Местную правку отслеживаемого файла сохраняют отдельной копией для разбора и оформляют через PR; автоматически её не исправляют и не удаляют.
